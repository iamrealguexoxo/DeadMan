# 💀 Dead Man Switch v1.0 - Initial Release 💀

## Was ist das?

Dead Man Switch ist ein Windows-basiertes automatisches Datenvernichtungssystem, das nach X Tagen ohne Login ausgelöst wird. Perfekt für Datenschutz und Sicherheit!

## ✨ Features

- 🎨 **GUI Control Panel** - Einfache Konfiguration per Doppelklick
- 🛡️ **Safe Mode** - Teste alles ohne echte Löschung (Simulation)
- 📁 **Multi-Format Support**:
  - Plain Dateien & Ordner
  - VeraCrypt Container & Keyfiles
  - BitLocker Recovery Keys
- ⚙️ **Windows Tasks** - Automatische Überwachung bei Login & Systemstart
- 🕺 **Dancing Bart** - Im About-Dialog (weil warum nicht?)
- 📝 **Vollständige Deutsche Dokumentation**

## 🚀 Quick Start

1. **Download** das ZIP
2. **Entpacken** nach `C:\DeadMan` (oder beliebigen Ort)
3. **Als Admin ausführen**: `install.bat`
4. **GUI starten**: `start.bat`
5. **Konfigurieren** und im Safe Mode testen!

## ⚠️ WICHTIG

**Safe Mode ist standardmäßig aktiviert!** Das System löscht NICHTS, solange Safe Mode an ist. Teste gründlich bevor du ihn deaktivierst!
